## 💡 Core Portfolio Features

- **Executive Hero & Dual Photo Switcher**: Features professional portrait (`/profile.jpg`) alongside a generated **3D AI Data Engineer Avatar** (`/avatar.png`) with 1-click view toggle.
- **Quantified Business Impact Cards**:
  - **+30% Pipeline Reliability & Scalability** (*Amazon - AWS Glue & Informatica*)
  - **-50% Data Anomaly Reduction** (*Amazon - Python & Redshift*)
  - **95% Extraction Accuracy** (*UMBC Research - YOLO-based CNN*)
  - **-15% Fraud False Positives** (*Global Payments*)
- **Interactive Technical Skills Matrix**: Categorized tech stack with real-time keyword search (*AWS Glue, Redshift, Spark, Python, SQL, Tableau, Power BI*).
- **Interactive ETL & SQL Pipeline Playground**: Browser simulator to view and execute production AWS Redshift SQL data quality audits and AWS Glue PySpark streaming jobs.
- **Master's Degree Research Showcase**: Deep breakdown of UMBC research projects (*Real-Time License Plate Detection, Chicago Crime Analytics, Credit Card Fraud Prediction*) with interactive architecture popups.
- **Printable Master Resume Viewer**: Native 1-click **Print / Save as PDF** and **Copy Raw Text** modal.

## 🔧 Local Development & Setup

```bash
# 1. Clone the repository
git clone https://github.com/krishnasidhvi/portfolio.git
cd portfolio

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
# Server running at http://localhost:3000

# 4. Build for production
npm run build
```
